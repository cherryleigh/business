GROUP 1: STUDY REVIEWER

1. Applying the Law of Cosines in Solving Oblique Triangles

An oblique triangle is a triangle that does not have a 90° angle. There are two types:

  • Acute triangle: All angles are less than 90°.
  • Obtuse triangle: One angle is greater than 90°.

Law of Cosines Formulas:

  • a² = b² + c² − 2bc cos A
  • b² = a² + c² − 2ac cos B
  • c² = a² + b² − 2ab cos C

Remember: The lowercase letter and uppercase letter are opposite each other (A ↔ a, B ↔ b, C ↔ c).

When to use:

  • SAS (Side-Angle-Side): Use when you know two sides and the angle between them to find the missing side.
  • SSS (Side-Side-Side): Use when you know all three sides to find a missing angle.

2. Solving Quadratic Inequalities in One Variable

A quadratic inequality in one variable contains a variable raised to the second power (e.g., x² + 3x − 4 > 0, x² − 5x + 6 ≤ 0, 2x² + x − 3 ≥ 0).

Symbols & Interval Notation:

  • Parentheses ( ): Endpoint is NOT included. Used with strict inequalities (< or >). Example: x > 3 → (3, ∞)
  • Brackets [ ]: Endpoint IS included. Used with non-strict inequalities (≤ or ≥). Example: x ≥ 3 → [3, ∞)

3. Solving Quadratic Inequalities in Two Variables

Standard forms (where a ≠ 0): y > ax² + bx + c, y ≥ ax² + bx + c, y < ax² + bx + c, y ≤ ax² + bx + c. These yield an infinite set of ordered pairs (x, y) representing a shaded region on the Cartesian plane.

4-Step Procedure:

  1. Find Key Features: Parabola orientation (a > 0 opens upward, a < 0 opens downward), vertex (h, k) where h = -b/2a, y-intercept (0, c), and x-intercepts (set y = 0).
  2. Draw Boundary Curve: Use a dashed parabola for strict inequalities (< or >); use a solid parabola for non-strict inequalities (≤ or ≥).
  3. Select a Test Point: Substitute a point not on the parabola (e.g., 0,0) into the original inequality to check if it returns true or false.
  4. Shade Solution Region: Shade the region containing the test point if true, or the opposite region if false. (Shortcut: y > or y ≥ shade above/inside upward parabola; y < or y ≤ shade below/outside upward parabola).

4. Determining the Region of Solutions (Linear vs. Quadratic)

Evaluating region of solutions in coordinate planes:

  • Boundary Lines: Strict inequalities (< or >) use dashed boundaries. Non-strict inequalities (≤ or ≥) use solid boundaries.
  • Shading Directions:
    • Linear: y > or y ≥ shades above; y < or y ≤ shades below.
    • Quadratic: y > or y ≥ shades above/inside upward parabola; y < or y ≤ shades below/outside upward parabola.
  • Systems: The solution set is the overlapping shaded region.

5. Absolute Value Equations in One Variable

Absolute value is the distance of a number from 0 on the number line.

Rule: If |x| = a, then x = a OR x = -a.

Example: |x| = 5 → x = 5 OR x = -5. Solution set: {-5, 5}.

6. Absolute Value Inequalities in One Variable

  • Less Than (AND / Between): |x| < a → -a < x < a. Example: |x| < 5 → -5 < x < 5 → Interval: (-5, 5)
  • Greater Than (OR / Outside): |x| > a → x < -a OR x > a. Example: |x| > 5 → x < -5 OR x > 5 → Interval: (-∞, -5) ∪ (5, ∞)

7. Measures of Position

Measures of position indicate where a value is located in an ordered data set.

  • Quartiles (Q): Divide data into 4 equal parts (Q1 = 25%, Q2 = 50%/Median, Q3 = 75%). Position formula: Pos = k(n + 1) / 4
  • Deciles (D): Divide data into 10 equal parts (D1 to D9; D5 = Median). Position formula: Pos = k(n + 1) / 10
  • Percentiles (P): Divide data into 100 equal parts (P1 to P99). Position formula: Pos = k(n + 1) / 100

Key Equivalencies: P25 = Q1 | P50 = Q2 = D5 = Median | P75 = Q3 | D1 = P10 | D9 = P90

Interpolation Formula: [(Larger - Smaller) × decimal] + Smaller

Interquartile Range (IQR) & Outliers:

  • IQR = Q3 - Q1
  • Lower Fence = Q1 - (1.5 × IQR)
  • Upper Fence = Q3 + (1.5 × IQR)
  • Any value outside these fences is an outlier.

Interpretation Note: Being at the 80th percentile means a score is at or above 80% of the data; it does not mean getting 80% on the test.

8. Box-and-Whisker Plots & Cumulative Frequency Visuals

  • Box-and-Whisker Plot: Displays the 5-number summary: Minimum, Q1, Median (Q2), Q3, and Maximum. The box represents the middle 50% (IQR).
  • Cumulative Frequency: The running total of frequencies. The last cumulative frequency equals total frequency (n).
  • Histogram & Polygon (Ogive): Visual representations of cumulative totals plotted against upper class boundaries.

9. Calculate Percentile Rank from Ungrouped Data

Steps to solve position:

  1. Arrange data in ascending order.
  2. Identify requested percentile k and total sample size n.
  3. Use formula: Pk = k(n + 1) / 100.

10. Drawing Conclusions Based on Statistical Data

Always interpret the numerical position relative to the whole set (e.g., A score at Q3/D7/P75 means performing better than approximately 75%/70% of the group).

GROUP 2: QUESTIONS & ANSWERS

Q1: How do you solve for side 'a' in an oblique triangle using the Law of Cosines when b = 5, c = 8, and angle A = 60°?
Answer: Use a² = b² + c² − 2bc cos A. Substitute the values: a² = (5)² + (8)² − 2(5)(8) cos(60°). Since cos(60°) = 0.5, a² = 25 + 64 − 80(0.5) = 89 − 40 = 49. Taking the square root gives a = 7.
Q2: How is the solution to x² − 5x + 6 ≤ 0 written in interval notation?
Answer: Factoring gives critical boundary points x = 2 and x = 3. Because the inequality symbol is "≤" (less than or equal to), endpoints are included and represented by brackets. The solution set is [2, 3].
Q3: Should the graph of the boundary for y > 2x² + x − 3 be solid or dashed, and which area should be shaded?
Answer: It should be a dashed parabola because it uses a strict inequality (>). Since y > and the parabola opens upward (a = 2 > 0), shade the region above/inside the parabola.
Q4: How do you identify the solution set for a system of linear and quadratic inequalities on a graph?
Answer: The solution set is the overlapping region where the shaded area satisfying the linear inequality intersects with the shaded area satisfying the quadratic inequality.
Q5: What are the solution steps and final set for the absolute value equation |2x − 3| = 7?
Answer: Split into two equations: 2x − 3 = 7 and 2x − 3 = -7. Solving the first gives 2x = 10 → x = 5. Solving the second gives 2x = -4 → x = -2. The solution set is {-2, 5}.
Q6: How do you solve and write the interval notation for |x − 2| > 4?
Answer: Use the "OR" rule: x − 2 < -4 OR x − 2 > 4. Solving gives x < -2 OR x > 6. In interval notation, this is (-∞, -2) ∪ (6, ∞).
Q7: How do you calculate Q1 using interpolation for the dataset: 5, 8, 12, 15, 18, 20, 24, 27, 30, 35 (n = 10)?
Answer: Calculate position: Pos = 1(10 + 1) / 4 = 2.75. The 2nd value is 8 and 3rd is 12. Apply interpolation: [(12 − 8) × 0.75] + 8 = [(4) × 0.75] + 8 = 3 + 8 = 11. Thus, Q1 = 11.
Q8: What five statistical values are needed to construct a Box-and-Whisker Plot?
Answer: The 5-number summary consists of: Minimum, First Quartile (Q1), Median (Q2), Third Quartile (Q3), and Maximum.
Q9: For a 15-item dataset, what is the position result when calculating the 70th percentile rank?
Answer: Use formula Pk = k(n + 1) / 100. Substitute values: P70 = 70(15 + 1) / 100 = 70(16) / 100 = 1120 / 100 = 11.2.
Q10: What conclusion can be drawn if a student ranks at the 90th percentile on a exam?
Answer: The student performed better than approximately 90% of the students who took the test.

GROUP 3: REAL-LIFE APPLICATIONS

Mathematical Topic Real-Life Application Example
1. Law of Cosines Navigation & Surveying: Ships and aircraft use it to calculate direct distance between two points when obstacles prevent straight measurement, using two known sides and the included angle.
2. Quadratic Inequalities (1 Var) Business Profit Margin: Determining the range of product selling prices that will guarantee a company yields a profit higher than zero (Profit > 0).
3. Quadratic Inequalities (2 Var) Architecture & Engineering: Designing tunnel or bridge clearance zones to ensure tall trucks fit safely within the parabolic arch shape.
4. Solution Regions Manufacturing Constraints: Determining feasible production volumes when limited by both maximum material availability (linear) and machine runtime curves (quadratic).
5. Absolute Value Equations Quality Control Manufacturing: Checking acceptable length variations for machine parts (e.g., verifying a target size of 10 cm with an error margin limit of ±0.05 cm).
6. Absolute Value Inequalities Thermostat & Climate Control: Programming HVAC systems to trigger temperature adjustments whenever room temperature strays outside a safe range (|T - 70| > 3).
7. Measures of Position Pediatric Health Charts: Tracking children's growth metrics over time to determine if height or weight falls within typical developmental percentile ranges.
8. Box Plots & Ogives Real Estate Analysis: Home buyers reviewing house price distributions in a neighborhood to see median costs and middle 50% price ranges without skewing from extreme luxury homes.
9. Percentile Rank Calculation Standardized College Testing: Admissions boards using student percentile ranks on national exams to evaluate candidates relative to the entire national applicant pool.
10. Statistical Conclusions Employee Wage Analysis: HR departments using deciles to ensure salary distributions across company tiers are equitable and competitive.
