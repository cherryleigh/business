1. Applying the Law of Cosines in Solving Oblique Triangles

What is an oblique triangle?
An oblique triangle is a triangle that does not have a 90° angle.[cite: 7]

There are two types:

  • Acute triangle – all angles are less than 90°[cite: 7]
  • Obtuse triangle – one angle is greater than 90°[cite: 7]

The Law of Cosines is used to solve for missing sides or angles in oblique triangles.[cite: 7]

Law of Cosines Formula

There are three forms:

a² = b² + c² − 2bc cos A
b² = a² + c² − 2ac cos B
c² = a² + b² − 2ab cos C[cite: 7]
REMEMBER! The lowercase letter and uppercase letter are opposite each other: A ↔ a | B ↔ b | C ↔ c[cite: 7]

When to Use the Law of Cosines?

  • SAS (Side-Angle-Side): Use this when you know two sides and the angle between them. It is usually used to find the missing side.[cite: 7]
  • SSS (Side-Side-Side): Use this when you know all three sides. It is usually used to find a missing angle.[cite: 7]

2. Solving Quadratic Inequalities in One Variable

What is a Quadratic Inequality?
A quadratic inequality is an inequality that contains a variable raised to the second power.[cite: 7]

Examples:

  • x² + 3x − 4 > 0[cite: 7]
  • x² − 5x + 6 ≤ 0[cite: 7]
  • 2x² + x − 3 ≥ 0[cite: 7]

The symbols used are:

  • > = greater than[cite: 7]
  • < = less than[cite: 7]
  • ≥ = greater than or equal to[cite: 7]
  • ≤ = less than or equal to[cite: 7]

Interval Notation

  • Parentheses ( ): The endpoint is NOT included. Used with < or >.[cite: 7]
    Example: x > 3 → (3, ∞)[cite: 7]
  • Brackets [ ]: The endpoint IS included. Used with ≤ or ≥.[cite: 7]
    Example: x ≥ 3 → [3, ∞)[cite: 7]
REMEMBER!
< or > → NOT included
≤ or ≥ → INCLUDED[cite: 7]

3. Solving Quadratic Inequalities in Two Variables

A quadratic inequality in two variables is an inequality that can be written in any of the following standard forms (where a ≠ 0):[cite: 7]

y > ax² + bx + c
y ≥ ax² + bx + c
y < ax² + bx + c
y ≤ ax² + bx + c[cite: 7]

Unlike quadratic equations (which yield specific boundary points or curves), quadratic inequalities yield an infinite set of ordered pairs (x, y) representing a shaded region on the Cartesian plane.[cite: 7]

4-Step Procedure for Solving

  1. Find Key Features of the Parabola: Vertex, orientation, and intercepts to graph the boundary parabola y = ax² + bx + c.[cite: 7]
    • Orientation: If a > 0, the parabola opens upward. If a < 0, it opens downward.[cite: 7]
    • Vertex (h, k): Calculate the x-coordinate using h = -b / 2a, then plug h back into the equation to get k.[cite: 7]
    • x-intercepts: Set y = 0 and solve for x using factoring or the quadratic formula.[cite: 7]
    • y-intercept: Set x = 0, giving (0, c).[cite: 7]
  2. Draw the Boundary Curve: Solid vs. Dashed[cite: 7]
    • Use a dashed parabola for strict inequalities (< or >). Boundary points are not included.[cite: 7]
    • Use a solid parabola for non-strict inequalities (≤ or ≥). Boundary points are included.[cite: 7]
  3. Select a Test Point: Choose a point not lying on the parabola (origin (0,0) is usually easiest).[cite: 7]
    • If true: The region containing that test point is part of the solution set.[cite: 7]
    • If false: The region containing that test point is not a solution.[cite: 7]
  4. Shade the Solution Region: Shade the region containing (0,0) if true, or the opposite if false.[cite: 7]
    • Shortcut (when solved for y): y > or y ≥ shades above/inside an upward parabola. y < or y ≤ shades below/outside an upward parabola.[cite: 7]

4. Determining the Region of Solutions (Linear vs. Quadratic)

The region of solutions is the shaded area in the coordinate plane containing all ordered pairs (x, y) that satisfy an inequality (or system of inequalities).[cite: 7]

Evaluate three core properties:[cite: 7]

  • Boundary Type: Solid vs. Dashed line/curve.[cite: 7]
  • Half-Plane / Curve Region: Identifying whether solution lies above, below, inside, or outside.[cite: 7]
  • Overlapping Region (Systems): The intersection where shading overlaps.[cite: 7]

Reference Rules

Boundary Types:

  • Strict (< or >): Dashed boundary. Points on boundary are not solutions.[cite: 7]
  • Non-Strict (≤ or ≥): Solid boundary. Points on boundary are solutions.[cite: 7]

Shading Directions (when solved for y):

  • Linear Inequalities: Use y > or y ≥ to shade above; y < or y ≤ to shade below.[cite: 7]
  • Quadratic Inequalities: Use y > or y ≥ to shade above/inside an upward parabola; y < or y ≤ to shade below/outside an upward parabola.[cite: 7]

5. Absolute Value Equations in One Variable

Absolute Value: The distance of a number from 0 on the number line.[cite: 7]
Absolute Value Equation: An equation containing an absolute value.[cite: 7]

Rule: |x| = a → x = a OR x = -a[cite: 7]

Example:
|x| = 5
x = 5 OR x = -5
Solution: {-5, 5}[cite: 7]

Various Notations:

  • Set notation: {-5, 5}[cite: 7]
  • Number line: ● at -5 and 5[cite: 7]

6. Absolute Value Inequalities in One Variable

Absolute Value Inequality: An inequality containing an absolute value.[cite: 7]

Less Than

|x| < a → -a < x < a[cite: 7]

Example: |x| < 5 → -5 < x < 5 → Interval: (-5, 5)[cite: 7]

Greater Than

|x| > a → x < -a OR x > a[cite: 7]

Example: |x| > 5 → x < -5 OR x > 5 → Interval: (-∞, -5) ∪ (5, ∞)[cite: 7]

REMEMBER:
Less than = BETWEEN = AND
Greater than = OUTSIDE = OR[cite: 7]

7. Illustrate Measures of Position (Quartiles, Deciles, and Percentiles)

Measures of position tell you where a value is located in an ordered data set. Always arrange the data from smallest to largest before finding a measure.[cite: 7]

Quartiles (Q)

Divides data into 4 equal parts:[cite: 7]

  • Q₁ = 25% of data are below it[cite: 7]
  • Q₂ = 50% of data are below it (Median)[cite: 7]
  • Q₃ = 75% of data are below it[cite: 7]

Position Formula (Ungrouped): Position of Qₖ = k(n + 1) / 4[cite: 7]

Deciles (D)

Divides data into 10 equal parts (D₁ to D₉). D₅ = Median.[cite: 7]

Position Formula: Position of Dₖ = k(n + 1) / 10[cite: 7]

Percentiles (P)

Divides data into 100 equal parts (P₁ to P₉₉).[cite: 7]

Position Formula: Position of Pₖ = k(n + 1) / 100[cite: 7]

Equivalencies: P₂₅ = Q₁ | P₅₀ = Q₂ = D₅ = Median | P₇₅ = Q₃ | D₁ = P₁₀ | D₉ = P₉₀[cite: 7]

Decimal Positions & Interpolation

If position is a decimal (e.g., 3.5), it means halfway between the 3rd and 4th values.[cite: 7]

Interpolation Formula: [(Larger − Smaller) × decimal] + Smaller[cite: 7]

Example: Data: 5, 8, 12, 15, 18, 20, 24, 27, 30, 35. Find Q₁ (n=10).[cite: 7]
Position = 1(10+1)/4 = 2.75[cite: 7]
Smaller (2nd) = 8, Larger (3rd) = 12, Decimal = 0.75[cite: 7]
Q₁ = [(12 − 8)(0.75)] + 8 = [(4)(0.75)] + 8 = 3 + 8 = 11[cite: 7]

Interquartile Range (IQR) & Outliers

IQR Formula: IQR = Q₃ − Q₁[cite: 7]

Outlier 1.5 × IQR Rule:[cite: 7]

  • Lower fence = Q₁ − (1.5 × IQR)[cite: 7]
  • Upper fence = Q₃ + (1.5 × IQR)[cite: 7]
  • Any value below lower fence or above upper fence = Outlier[cite: 7]

How to Interpret Percentiles

80th percentile means score is at or above ~80% of the data. 80th percentile ≠ 80% score. It represents rank, not percentage of correct answers.[cite: 7]

8. Construct and Interpret Plots, Histograms, and Polygons

I. Box-and-Whisker Plot

Shows the Five-Number Summary: Minimum, Q₁, Median (Q₂), Q₃, Maximum[cite: 7]

  • Left whisker → Minimum to Q₁[cite: 7]
  • Box → Q₁ to Q₃ (Middle 50% of data)[cite: 7]
  • Line inside box → Median[cite: 7]
  • Right whisker → Q₃ to Maximum[cite: 7]

9. Calculate the Percentile Rank from Ungrouped Data

Tells relative position compared to other scores.[cite: 7]

Example: Find position for 70th percentile from 100-item quiz scores: 68, 50, 85, 60, 92, 45, 75, 82, 55, 90, 62, 80, 65, 88, 70[cite: 7]

  1. Arrange data in ascending order:
    45, 50, 55, 60, 62, 65, 68, 70, 75, 80, 82, 85, 88, 90, 92[cite: 7]
  2. Identify values: k = 70, n = 15[cite: 7]
  3. Input into formula: Pₖ = k(n + 1) / 100[cite: 7]
  4. Solve:
    P₇₀ = 70(15 + 1) / 100
    P₇₀ = 70(16) / 100
    P₇₀ = 1120 / 100 = 11.2[cite: 7]

10. Draw Conclusions Based on Statistical Data Using Measures of Position

When drawing conclusions, explain what the value means in relation to the dataset rather than just giving a numerical answer.[cite: 7]

Examples of Drawing Conclusions

  • Percentile (90th Percentile): The student performed better than approximately 90% of the scores in the dataset.[cite: 7]
  • Quartile (Q₃ - Third Quartile): Since Q₃ represents the 75th percentile, the score is higher than approximately 75% of the data.[cite: 7]
  • Decile (D₇ - Seventh Decile): Since D₇ represents the 70th percentile, the score is higher than approximately 70% of the data.[cite: 7]
