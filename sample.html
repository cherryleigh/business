Quick Reference

Grade 10 Formulas Cheat Sheet

Law of Cosines

Used for oblique triangles given SAS or SSS.

  • a² = b² + c² - 2bc cos(A)
  • b² = a² + c² - 2ac cos(B)
  • c² = a² + b² - 2ab cos(C)

Measures of Position

Used to find data locations in an ordered set.

  • Quartiles (Q): Divides into 4. Qk = k(n+1)/4
  • Deciles (D): Divides into 10. Dk = k(n+1)/10
  • Equivalencies: Q2 = D5 = P50 (Median)

Quadratic Inequalities

Strict (<, >)
Uses dashed boundary lines. Parentheses ( ) in interval notation.
Non-Strict (≤, ≥)
Uses solid boundary lines. Brackets [ ] in interval notation.
