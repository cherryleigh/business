1. Applying the Law of Cosines in Solving Oblique Triangles ▼

What is an oblique triangle?
An oblique triangle is a triangle that does not have a 90° angle.

There are two types:

  • Acute triangle – all angles are less than 90°
  • Obtuse triangle – one angle is greater than 90°

The Law of Cosines is used to solve for missing sides or angles in oblique triangles.

Law of Cosines Formula

There are three forms:

a² = b² + c² − 2bc cos A
b² = a² + c² − 2ac cos B
c² = a² + b² − 2ab cos C
REMEMBER! The lowercase letter and uppercase letter are opposite each other: A ↔ a | B ↔ b | C ↔ c

When to Use the Law of Cosines?

  • SAS (Side-Angle-Side): Use this when you know two sides and the angle between them. It is usually used to find the missing side.
  • SSS (Side-Side-Side): Use this when you know all three sides. It is usually used to find a missing angle.

Practice Questions

Q1: When should you use the Law of Cosines to solve for a missing angle?
Use it under the SSS (Side-Side-Side) condition—when all three sides of the oblique triangle are known.
2. Solving Quadratic Inequalities in One Variable ▼

What is a Quadratic Inequality?
A quadratic inequality is an inequality that contains a variable raised to the second power.

Examples:

  • x² + 3x − 4 > 0
  • x² − 5x + 6 ≤ 0
  • 2x² + x − 3 ≥ 0

The symbols used are:

  • > = greater than
  • < = less than
  • ≥ = greater than or equal to
  • ≤ = less than or equal to

Interval Notation

  • Parentheses ( ): The endpoint is NOT included. Used with < or >.
    Example: x > 3 → (3, ∞)
  • Brackets [ ]: The endpoint IS included. Used with ≤ or ≥.
    Example: x ≥ 3 → [3, ∞)
REMEMBER!
< or > → NOT included
≤ or ≥ → INCLUDED

Practice Questions

Q1: What symbol format is used in interval notation for a non-strict inequality like ≤ or ≥?
Brackets [ ] are used because the endpoint is included in the solution set.
3. Solving Quadratic Inequalities in Two Variables ▼

A quadratic inequality in two variables is an inequality that can be written in any of the following standard forms (where a ≠ 0):

y > ax² + bx + c
y ≥ ax² + bx + c
y < ax² + bx + c
y ≤ ax² + bx + c

Unlike quadratic equations (which yield specific boundary points or curves), quadratic inequalities yield an infinite set of ordered pairs (x, y) representing a shaded region on the Cartesian plane.

4-Step Procedure for Solving

  1. Find Key Features of the Parabola: Vertex, orientation, and intercepts to graph the boundary parabola y = ax² + bx + c.
    • Orientation: If a > 0, the parabola opens upward. If a < 0, it opens downward.
    • Vertex (h, k): Calculate the x-coordinate using h = -b / 2a, then plug h back into the equation to get k.
    • x-intercepts: Set y = 0 and solve for x using factoring or the quadratic formula.
    • y-intercept: Set x = 0, giving (0, c).
  2. Draw the Boundary Curve: Solid vs. Dashed
    • Use a dashed parabola for strict inequalities (< or >). Boundary points are not included.
    • Use a solid parabola for non-strict inequalities (≤ or ≥). Boundary points are included.
  3. Select a Test Point: Choose a point not lying on the parabola (origin (0,0) is usually easiest).
    • If true: The region containing that test point is part of the solution set.
    • If false: The region containing that test point is not a solution.
  4. Shade the Solution Region: Shade the region containing (0,0) if true, or the opposite if false.
    • Shortcut (when solved for y): y > or y ≥ shades above/inside an upward parabola. y < or y ≤ shades below/outside an upward parabola.

Practice Questions

Q1: How do you know whether to graph a solid or dashed boundary parabola?
Use a dashed parabola for strict inequalities (< or >) and a solid parabola for non-strict inequalities (≤ or ≥).
4. Determining the Region of Solutions (Linear vs. Quadratic) ▼

The region of solutions is the shaded area in the coordinate plane containing all ordered pairs (x, y) that satisfy an inequality (or system of inequalities).

Evaluate three core properties:

  • Boundary Type: Solid vs. Dashed line/curve.
  • Half-Plane / Curve Region: Identifying whether solution lies above, below, inside, or outside.
  • Overlapping Region (Systems): The intersection where shading overlaps.

Reference Rules

Boundary Types:

  • Strict (< or >): Dashed boundary. Points on boundary are not solutions.
  • Non-Strict (≤ or ≥): Solid boundary. Points on boundary are solutions.

Shading Directions (when solved for y):

  • Linear Inequalities: Use y > or y ≥ to shade above; y < or y ≤ to shade below.
  • Quadratic Inequalities: Use y > or y ≥ to shade above/inside an upward parabola; y < or y ≤ to shade below/outside an upward parabola.

Practice Questions

Q1: For a system of linear and quadratic inequalities, what constitutes the final solution region?
The intersection or overlapping region where the shaded regions of all inequalities in the system overlap simultaneously.
5. Absolute Value Equations in One Variable ▼

Absolute Value: The distance of a number from 0 on the number line.
Absolute Value Equation: An equation containing an absolute value.

Rule: |x| = a → x = a OR x = -a

Example:
|x| = 5
x = 5 OR x = -5
Solution: {-5, 5}

Various Notations:

  • Set notation: {-5, 5}
  • Number line: ● at -5 and 5

Practice Questions

Q1: Solve for x: |x| = 12. Write answer in set notation.
x = 12 OR x = -12. In set notation: {-12, 12}
6. Absolute Value Inequalities in One Variable ▼

Absolute Value Inequality: An inequality containing an absolute value.

Less Than

|x| < a → -a < x < a

Example: |x| < 5 → -5 < x < 5 → Interval: (-5, 5)

Greater Than

|x| > a → x < -a OR x > a

Example: |x| > 5 → x < -5 OR x > 5 → Interval: (-∞, -5) ∪ (5, ∞)

REMEMBER:
Less than = BETWEEN = AND
Greater than = OUTSIDE = OR

Practice Questions

Q1: Express the inequality |x| > 8 as a compound inequality statement.
x < -8 OR x > 8
7. Illustrate Measures of Position (Quartiles, Deciles, and Percentiles) ▼

Measures of position tell you where a value is located in an ordered data set. Always arrange the data from smallest to largest before finding a measure.

Quartiles (Q)

Divides data into 4 equal parts:

  • Q₁ = 25% of data are below it
  • Q₂ = 50% of data are below it (Median)
  • Q₃ = 75% of data are below it

Position Formula (Ungrouped): Position of Qₖ = k(n + 1) / 4

Deciles (D)

Divides data into 10 equal parts (D₁ to D₉). D₅ = Median.

Position Formula: Position of Dₖ = k(n + 1) / 10

Percentiles (P)

Divides data into 100 equal parts (P₁ to P₉₉).

Position Formula: Position of Pₖ = k(n + 1) / 100

Equivalencies: P₂₅ = Q₁ | P₅₀ = Q₂ = D₅ = Median | P₇₅ = Q₃ | D₁ = P₁₀ | D₉ = P₉₀

Decimal Positions & Interpolation

If position is a decimal (e.g., 3.5), it means halfway between the 3rd and 4th values.

Interpolation Formula: [(Larger − Smaller) × decimal] + Smaller

Example: Data: 5, 8, 12, 15, 18, 20, 24, 27, 30, 35. Find Q₁ (n=10).
Position = 1(10+1)/4 = 2.75
Smaller (2nd) = 8, Larger (3rd) = 12, Decimal = 0.75
Q₁ = [(12 − 8)(0.75)] + 8 = [(4)(0.75)] + 8 = 3 + 8 = 11

Interquartile Range (IQR) & Outliers

IQR Formula: IQR = Q₃ − Q₁

Outlier 1.5 × IQR Rule:

  • Lower fence = Q₁ − (1.5 × IQR)
  • Upper fence = Q₃ + (1.5 × IQR)
  • Any value below lower fence or above upper fence = Outlier

How to Interpret Percentiles

80th percentile means score is at or above ~80% of the data. 80th percentile ≠ 80% score. It represents rank, not percentage of correct answers.

Practice Questions

Q1: What decile position is equivalent to the Median and the 50th Percentile?
D₅ (5th Decile)
8. Construct and Interpret Plots, Histograms, and Polygons ▼

I. Box-and-Whisker Plot

Shows the Five-Number Summary: Minimum, Q₁, Median (Q₂), Q₃, Maximum

  • Left whisker → Minimum to Q₁
  • Box → Q₁ to Q₃ (Middle 50% of data)
  • Line inside box → Median
  • Right whisker → Q₃ to Maximum

II. Cumulative Frequency

The running total of frequencies. The last cumulative frequency = total frequency (n).

Score Frequency Cumulative Frequency
1033
2058 (3+5)
30412 (8+4)
40618 (12+6)

III. Cumulative Frequency Histogram & Polygon

  • Histogram: Visualizes how cumulative totals increase across classes/values (x-axis: values, y-axis: cumulative frequency).
  • Polygon (Ogive): Created by plotting cumulative frequency points and connecting them with straight line segments.

Practice Questions

Q1: What percentage of the data does the central "box" in a box-and-whisker plot represent?
It represents the middle 50% of the data (from Q₁ to Q₃).
9. Calculate the Percentile Rank from Ungrouped Data ▼

Tells relative position compared to other scores.

Example: Find position for 70th percentile from 100-item quiz scores: 68, 50, 85, 60, 92, 45, 75, 82, 55, 90, 62, 80, 65, 88, 70

  1. Arrange data in ascending order:
    45, 50, 55, 60, 62, 65, 68, 70, 75, 80, 82, 85, 88, 90, 92
  2. Identify values: k = 70, n = 15
  3. Input into formula: Pₖ = k(n + 1) / 100
  4. Solve:
    P₇₀ = 70(15 + 1) / 100
    P₇₀ = 70(16) / 100
    P₇₀ = 1120 / 100 = 11.2

Practice Questions

Q1: What is the mandatory first step before applying any measure of position formula?
Arrange the data in ascending order (smallest to largest).
10. Draw Conclusions Based on Statistical Data Using Measures of Position ▼

When drawing conclusions, explain what the value means in relation to the dataset rather than just giving a numerical answer.

Examples of Drawing Conclusions

  • Percentile (90th Percentile): The student performed better than approximately 90% of the scores in the dataset.
  • Quartile (Q₃ - Third Quartile): Since Q₃ represents the 75th percentile, the score is higher than approximately 75% of the data.
  • Decile (D₇ - Seventh Decile): Since D₇ represents the 70th percentile, the score is higher than approximately 70% of the data.

Practice Questions

Q1: Does scoring at the 85th percentile mean a student scored 85% on an exam?
No. It means the student performed better than or equal to approximately 85% of the test-takers, not that they got 85% of answers correct.
