1. Applying the Law of Cosines in Solving Oblique Triangles

An oblique triangle is a triangle that does not have a 90° right angle. It can be:

  • Acute triangle: All angles are less than 90°.
  • Obtuse triangle: One angle is greater than 90°.

Law of Cosines Formulas

a² = b² + c² - 2bc cos A
b² = a² + c² - 2ac cos B
c² = a² + b² - 2ab cos C
REMEMBER! Lowercase letters represent side lengths, and uppercase letters represent their opposite angles (e.g., side a is opposite Angle A).

When to Use the Law of Cosines?

  • SAS (Side-Angle-Side): When you know two sides and the included angle between them. Used to find the missing side.
  • SSS (Side-Side-Side): When you know all three sides. Used to find a missing angle.

2. Solving Quadratic Inequalities in One Variable

A quadratic inequality contains a variable raised to the second power (e.g., x² + 3x - 4 > 0, x² - 5x + 6 ≤ 0).

Interval Notation Rules

  • Parentheses ( ): Used with < or > (Endpoint is NOT included). Example: x > 3 → (3, ∞)
  • Brackets [ ]: Used with ≤ or ≥ (Endpoint IS included). Example: x ≥ 3 → [3, ∞)

3. Solving Quadratic Inequalities in Two Variables

Standard forms: y > ax² + bx + c, y ≥ ax² + bx + c, y < ax² + bx + c, or y ≤ ax² + bx + c (where a ≠ 0). Solutions form an infinite set of ordered pairs (x, y) represented as a shaded region.

4-Step Procedure

  1. Key Features of Parabola: Determine orientation (a > 0 opens up, a < 0 opens down), vertex h = -b/(2a), x-intercepts (y = 0), and y-intercept (0, c).
  2. Draw Boundary Curve: Use a dashed line for strict inequalities (< or >) and a solid line for non-strict inequalities (≤ or ≥).
  3. Select a Test Point: Pick a point not on the curve (usually (0,0)) and test it in the inequality.
  4. Shade the Region: If the test point yields a true statement, shade the region containing it; otherwise, shade the opposite region.

4. Determining the Region of Solutions (Linear vs. Quadratic)

Evaluating boundary curves and shaded regions for linear and quadratic inequalities:

Type Strict (< or >) Non-Strict (≤ or ≥)
Boundary Line/Curve Dashed Line (Points NOT included) Solid Line (Points ARE included)
Linear Shading > Shade Above | < Shade Below ≥ Shade Above | ≤ Shade Below
Quadratic Shading (a > 0) > Shade Inside/Above | < Shade Outside/Below ≥ Shade Inside/Above | ≤ Shade Outside/Below

5. Absolute Value Equations in One Variable

Absolute value represents the distance of a number from 0 on a number line.

Rule: If |x| = a, then x = a OR x = -a

Example: |x| = 5 → Solution set: {-5, 5}

6. Absolute Value Inequalities in One Variable

  • Less Than (< or ≤): |x| < a → -a < x < a (BETWEEN / AND statement)
  • Greater Than (> or ≥): |x| > a → x < -a OR x > a (OUTSIDE / OR statement)

7. Measures of Position (Quartiles, Deciles, Percentiles)

Measures of position state where a value is located in an ordered dataset.

  • Quartiles (Q): Divide data into 4 equal parts. Position formula: Qk = k(n + 1) / 4
  • Deciles (D): Divide data into 10 equal parts. Position formula: Dk = k(n + 1) / 10
  • Percentiles (P): Divide data into 100 equal parts. Position formula: Pk = k(n + 1) / 100
Equivalences: Q1 = P25 | Q2 = D5 = P50 (Median) | Q3 = P75

Interpolation & Outliers

Interpolation Formula: Value = [(Larger - Smaller) × decimal] + Smaller

Interquartile Range (IQR): IQR = Q3 - Q1

Outlier Fences: Lower Fence = Q1 - 1.5(IQR) | Upper Fence = Q3 + 1.5(IQR)

8. Box-and-Whisker Plots & Cumulative Frequency

Five-Number Summary: Minimum, Q1, Median (Q2), Q3, Maximum.

Cumulative Frequency: Running total of frequencies. The last cumulative frequency equals total sample size (n).

Ogive: A line graph plotted using upper class boundaries and cumulative frequencies.

9. Drawing Conclusions from Statistical Data

Percentile rank measures relative position, not percentage of correct items. A student at the 80th percentile scored higher than or equal to roughly 80% of all participants.

Practice Questions

1. Which formula represents the Law of Cosines when solving for side 'a'?
2. Under which condition should you use the Law of Cosines to solve an oblique triangle?
3. What interval notation is used for x ≥ 3?
4. What type of boundary line should be drawn for strict inequalities such as y > ax² + bx + c?
5. What are the solutions to the absolute value equation |x| = 7?
6. Which measure of position is equivalent to the Median (Q2)?
7. If Q1 = 8 and Q3 = 18, what is the Interquartile Range (IQR)?
8. What 5 numbers make up the summary in a Box-and-Whisker Plot?

Answer Key & Solutions

1. A — Law of Cosines formula for side a is a² = b² + c² - 2bc cos A.

2. B — Law of Cosines is used when given SAS or SSS conditions.

3. B — Brackets [ ] are used when the endpoint is included (≥ or ≤).

4. B — Strict inequalities (< or >) use a dashed boundary line.

5. -7, 7 — Absolute value |x| = 7 gives x = 7 or x = -7.

6. A — The 5th decile (D5) and 50th percentile (P50) equal the Median (Q2).

7. 10 — IQR = Q3 - Q1 = 18 - 8 = 10.

8. B — The five-number summary consists of Min, Q1, Median, Q3, and Max.
